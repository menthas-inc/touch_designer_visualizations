# Docs

Start with the top-level `README.md`. Then:

- `tech/setup.md`: what the show machine has, the edit loop (script, dump, save), the tracker,
  reading a save without TouchDesigner.
- `tech/network.md`: the network operator by operator, as read from `td/network.json`. The
  longest read and the one that answers most questions.
- `tech/decisions.md`: technical decisions, newest first, and the open ones.
- `constitution/principles.md`: the few rules that are enforced, by review and by the commit
  hooks in `.claude/hooks/`.
- `specs/`: one folder per feature, each with the what, the how and the task list.
  `001-dynamic-effects` is the chain and the sequencer, `002-beat-sync` the tracker.
- `images/`: frames of the projector feed.

Dates in the docs are when something was decided or changed, not deadlines. "Owner" is the
person running the room.
